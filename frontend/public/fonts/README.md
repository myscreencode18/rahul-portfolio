# Font Assets

Place the following font files in this directory:

| File                        | Font Family   | Source                                      |
|-----------------------------|---------------|---------------------------------------------|
| Satoshi-Variable.woff2      | Satoshi       | https://www.fontshare.com/fonts/satoshi      |
| Switzer-Variable.woff2      | Switzer       | https://www.fontshare.com/fonts/switzer      |
| GeistMono-Variable.woff2    | Geist Mono    | https://vercel.com/font                      |

## Download Instructions

**Satoshi & Switzer** — Fontshare (free for commercial use):
1. Visit https://www.fontshare.com
2. Download Variable font format (.woff2)
3. Place in this directory

**Geist Mono** — Vercel (open source):
1. Visit https://vercel.com/font
2. Or: `npm install geist` and copy from node_modules

All fonts use `font-display: swap` for performance.
